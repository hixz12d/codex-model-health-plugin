## 账号模型体检 · 批量检测定制版

基于 R-lmmortal/codex-model-health-plugin v0.2.1，保留原 Meow / ModelTrace 检测算法、冻结基线及许可证。

### 功能

- 最多选择 16 个账号，按账号串行执行 Meow 或 ModelTrace 检测
- Meow 汇总目标模型匹配度、当前最高候选及其匹配度；未完成值标「暂定」，无有效样本不展示初始概率
- ModelTrace 完成三轮有效样本并得到最终归因后，展示结论和最高候选相对概率
- 完整报告点击「详情」展开，历史和说明默认折叠；桌面、手机与深色主题适配
- 支持暂停、继续和结束批次；隐藏页面后不再发送下一题，返回需手动继续
- 明确失败的账号不自动重试并继续后续账号；操作结果不确定时暂停批次，避免自动重复计量

### 安装

在现有插件的 GitHub 来源中填写：

```text
仓库：hixz12d/codex-model-health-plugin
标签：v0.2.2-hixz.1
```

选择 `local.model-health-0.2.2-hixz.1-x86_64-unknown-linux-gnu.tar.gz`，不要选择 Source code 压缩包。插件身份仍为 `local.model-health`；更新并切换现有插件，不要卸载重装。切换前先暂停检测，等待当前题完成。

平台：Linux x86_64、glibc 2.36+。清单宿主范围 `>=3.19.0, <4.0.0`，不扩展原兼容声明。

### 验证与边界

- 本地通过前端类型检查、构建、现有单元与浏览器验收，以及模拟账号批量流程；GitHub 发布前运行完整 Linux 构建和离线协议验收
- 未对生产实例执行安装或真实计费检测，界面截图均为模拟数据
- 批次只在当前页面存续；刷新/离开后不恢复队列。历史沿用原 16 槽位，不扩容、不清空已有记录
- 百分比是候选库内的行为匹配度或相对概率，不是模型身份认证
